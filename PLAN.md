# «Барабан задач» — план и инструкции для доработки

## Что уже есть (v1, файл `index.html`)
Вся игра лежит в одном файле. Никаких сборок, серверов и библиотек не нужно: файл открывается двойным кликом в браузере.

| Часть | Где в `index.html` | Что делает |
|---|---|---|
| Начальник службы связи | `<svg id="boss">` | SVG-персонаж в форме: фуражка, погоны, галстук, микрофон. При кручении указывает на барабан (класс `.pointing`), когда говорит, открывает рот (`.talking`) |
| Барабан | `<svg id="wheel">`, функция `buildWheel()` | Секторы строятся из массива `TASKS`, по ободу мигают лампочки, стрелка дёргается на каждом секторе |
| Кручение | функция `spin()` | Сектор выбирается заранее и случайно (два раза подряд одно задание не выпадает). Анимация длится 2,3–3 с с замедлением, на каждом секторе щёлкает звук |
| Лёха | `<svg id="lexa">` | Входит с шагом, потом в цикле: клюёт носом, щурит глаза, зевает, потеет, над ним летят «Zzz», пьёт чай |
| Табло | `#plaque` | Печатает текст задания по буквам |
| Усталость и журнал | `addTired()` | Шкала усталости и список выданных заданий |
| Звук | `tone()`, `fanfare()`, `sigh()` | Генерируется через WebAudio, без файлов |

## Как быстро поменять содержимое
- **Задания**: массив `TASKS` в начале `<script>`. Формат: `{icon:'🔌', short:'Кабель', v:['вариант 1', 'вариант 2', …]}`. Можно давать секторам разное число вариантов. `short` — подпись на секторе, лучше до 9 символов. Барабан сам подстраивает число секторов.
- **Фразы начальника**: массивы `BOSS_START` (фраза при запуске барабана) и `BOSS_RESULT` (фраза после выпадения задания). `{s}` заменяется названием сектора.
- **Фразы Лёхи**: массив `LEXA`.
- **Подписи к шкале усталости**: массив `TIRED` в формате `[порог в %, 'текст']`.
- **Цвета секторов**: массив `COLORS`.
- **Длительность кручения**: в `spin()` строка `dur = 2300 + Math.random()*700` (в миллисекундах).

## План развития (по этапам)
1. **Контент.** Заменить задания на настоящие рабочие шутки отдела. Добавить особые секторы:
   - «ПРЕМИЯ»: Лёха радуется, отдельная анимация с конфетти;
   - «ОТГУЛ»: Лёха убегает со сцены;
   - «БАНКРОТ»: усталость сбрасывается, журнал очищается.
2. **Анимации Лёхи по усталости.** Когда `tired > 60`, Лёха сильнее сутулится и потеет; когда `tired > 90`, засыпает стоя, а начальник его будит. Сделать это можно через CSS-класс на `#lexaSlot` (например, `.very-tired`) и отдельные `@keyframes`.
3. **Реакция на задание.** У каждого задания своя поза Лёхи: для «Мачты» он лезет по лестнице, для «Принтера» держит принтер. В `TASKS` нужно добавить поле `pose`, а в `finish()` вешать соответствующий класс.
4. **Буквенное табло как в «Поле чудес».** Ключевое слово задания открывается плитками по одной букве, со звуком на каждую.
5. **Режим «на двоих».** Кнопка «Подменить Лёху», которая выводит второго монтёра (другое имя, другая внешность).
6. **Сохранение.** Хранить журнал и усталость в `localStorage`, чтобы они не пропадали после перезагрузки.
7. **Полировка.** Фоновая «студийная» музыка с кнопкой mute, конфетти после фанфар, полноэкранный режим для показа на проекторе.

## Инструкция: как доделать в Antigravity
1. Откройте папку `игра леха` в Antigravity (File → Open Folder).
2. Откройте `index.html` в браузере, чтобы смотреть результат. После каждой правки достаточно обновить страницу (Cmd+R).
3. Давайте агенту задачи по одной и поимённо ссылайтесь на части файла. Готовые формулировки:
   - «В `index.html` в массив `TASKS` добавь 5 заданий про …»
   - «Добавь на барабан сектор ПРЕМИЯ. Если он выпадает, в `finish()` вызывай новую функцию `celebrate()`: конфетти на canvas поверх сцены и радостная фраза Лёхи. Лёха должен улыбаться: добавь в SVG `#lexa` элемент `mouth-happy` и показывай его через класс `.happy`.»
   - «Когда усталость выше 60%, ставь на `#lexaSlot` класс `.very-tired`. В этом состоянии кивок головы `.head` делай глубже и чаще, а капли пота `.sweat` крупнее.»
   - «Сохраняй `tired` и журнал `#log` в `localStorage` и восстанавливай при загрузке. Добавь кнопку "Новая смена", которая всё сбрасывает.»
4. Правила для агента (можно вставить в его системные правила или в начало запроса):
   - игра остаётся одним файлом `index.html`, без фреймворков и без сборки;
   - персонажи рисуются только SVG и CSS, анимации делаются через `@keyframes` и классы;
   - существующие функции `spin()`, `finish()`, `say()`, `lexaIn()` и `lexaOut()` не ломать, только расширять;
   - после каждого изменения проверять, что стрелка по-прежнему указывает на выпавший сектор.
5. Как проверить себя после правок: покрутите барабан 5–10 раз. Задание на табло должно совпадать с сектором под красной стрелкой, Лёха должен выходить каждый раз, а в консоли браузера (Cmd+Opt+J) не должно быть ошибок.

## Как устроен выбор сектора (пригодится при правках)
Секторы рисуются по часовой стрелке, сектор 0 начинается сверху. Стрелка стоит вверху. Чтобы под стрелкой оказался сектор `idx`, итоговый угол поворота должен удовлетворять условию `rot mod 360 = 360 − (idx·A + смещение)`, где `A = 360 / N`. Эта формула уже реализована в `spin()`. Если меняете рисование секторов, её нужно поправить вместе с ним.
